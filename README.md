# goal-scene-analyzer

RoboCup Soccer Simulation 2D の試合ログから、得点・失点直前の場面を抽出し、ボールや選手の軌道を分析・可視化するためのツールです。

## 目的
試合ログに含まれる時系列データを用いて、失点につながる守備場面の特徴を明らかにし、チーム戦略の改善に活用することを目的としています。

## 主な機能
- 試合ログから得点・失点場面を抽出
- ボール・選手位置の時系列データを取得
- 失点直前の場面を可視化
- DTWやクラスタリングによる類似場面分析
- 分析結果をもとに守備パターンを比較

## 使用技術
Python, NumPy, pandas, matplotlib, scikit-learn, tslearn
