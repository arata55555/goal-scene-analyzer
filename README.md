# goal-scene-analyzer

RoboCup Soccer Simulation 2D の試合ログを用いて、得点・失点直前の場面を抽出し、ボールや選手の位置関係を分析・可視化するためのツールです。

## 目的

試合ログに含まれる時系列の位置データを用いて、失点につながりやすい守備場面の特徴を明らかにすることを目的としています。  
分析結果をもとに、守備戦略や選手配置の改善につなげることを目指しています。

## 概要

本リポジトリでは、RoboCup Soccer Simulation 2D の試合ログから、得点・失点直前の場面を抽出し、ボールや選手の位置情報を整理します。

主な処理は以下の通りです。

1. rcgログから試合データを抽出
2. 得点・失点直前の場面データを作成
3. ボールや選手の位置関係を整理
4. 失点場面の特徴を分析
5. 分析結果を可視化

## 主な機能

- RoboCup Soccer Simulation 2D の試合ログを読み込み
- 得点・失点直前の場面を抽出
- ボール・選手の位置情報を整理
- 失点場面の特徴を分析
- 分析結果を図や表で可視化

## 使用技術

- Python
- NumPy
- pandas
- matplotlib
- scikit-learn

## 工夫した点

- 試合ログから必要な場面だけを抽出し、分析しやすい形に整理しました。
- ボールと選手の位置情報を用いて、失点直前の状況を比較できるようにしました。
- 分析結果を可視化することで、守備の課題を直感的に確認できるようにしました。
- 中間データや重いファイルをGit管理しないようにし、リポジトリを見やすく保つことを意識しました。

## 注意事項

本リポジトリには、研究データや大容量のログファイルは含めていません。  
主に、分析手順・コード構成・実装方針を確認できるようにしています。
