# goal-scene-analyzer

RoboCup Soccer Simulation 2D の試合ログを用いて、得点・失点直前の場面を抽出し、ボールや選手の軌道を分析・可視化するためのツールです。

## 目的

試合ログに含まれる時系列データを分析し、失点につながりやすい守備場面の特徴を明らかにすることを目的としています。  
分析結果をもとに、守備戦略や選手配置の改善につなげることを目指しています。

## 概要

本リポジトリでは、RoboCup Soccer Simulation 2D の試合ログから、得点・失点直前の場面を抽出し、ボールや選手の位置情報を時系列データとして分析します。

主な処理は以下の通りです。

1. rcgログから試合データを抽出
2. 得点・失点直前の軌道データを作成
3. LSTM系モデルを用いた軌道予測
4. 予測結果や誤差の可視化
5. 守備場面の特徴分析
